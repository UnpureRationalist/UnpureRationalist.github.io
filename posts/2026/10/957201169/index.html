LLM Systems 07: Pre-trained LLMs

  • Key components in Transformer

1. Pretrained Encoder-Decoder LLM: T5

  • Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer
  • arXiv 提交日期：23 Oct 2019；发表于 Journal of Machine Learning Research 2020
  • 作者：其中 Noam Shazeer 也是 Transformer 论文作者

1.1 Model Architecture & Model Size

  • 模型架构：标准 Encoder-Decoder Transformer
    • 解码方式 (Decoding)：Beam search（Beam width=4, Length penalty=0.6）
    • Length penalty=0.6：用于修正 Beam Search 对短序列的偏好。公式为 \(\frac{\log P}{|Y|^{0.6}}\)。0.6 是一个经验折中值，既避免了模型生成过短的残缺文本，又防止了生成过于冗长啰嗦的句子。
  • 模型规模：
    • T5-base: 220M parameters (12 blocks, \(d_{ff} = 3072\), \(d_{kv} = 64\), 12-headed attention, \(d_{model} = 768\))
    • T5-3B: 24 blocks, \(d_{model} = 1024\), \(d_{kv} = 128\), \(d_{ff} = 16384\), 32-headed attention
    • T5-11B: 24 blocks, \(d_{model} = 1024\), \(d_{kv} = 128\), \(d_{ff} = 65536\), 128-headed attention

注意： 上述 3B/11B 模型，不满足 \(d_{kv} \times h = d_{model}\) （其中 \(h\) 表示 MHA heads 数量）。这是因为 T5 模型修改了 Q/K/V/O 的权重矩阵的维度，对 Q/K/V 进行了维度扩展，然后进行 Attention 计算。相关代码如下：

  • https://github.com/huggingface/transformers/blob/main/src/transformers/models/t5/configuration_t5.py

  • https://github.com/huggingface/transformers/blob/main/src/transformers/models/t5/modeling_t5.py

1.2 Training

  • 整体流程：Pre-training \(\rightarrow\) Multitask Finetuning
  • Pre-training：
    • 数据集：C4 (Colossal Clean Crawled Corpus)，来自 Common Crawl 过滤出的英语语料库，规模 750GB。
    • 目标：Recover randomly corrupted spans（随机破坏 15% 的文本片段，Cloze-style，即：完形填空式预训练）。
    • 示例：Original: Thank you for inviting me to your party last week. -> Inputs: Thank you <X> me to your party <Y> week. -> Targets: <X> for inviting <Y> last <Z>
    • 哨兵 token (Sentinel Tokens)：T5 词表中额外的 100 个特殊 token（<extra_id_0> ~ <extra_id_99>，上述示例简写为 <X>, <Y>, <Z>）。在输入中充当被挖空片段的占位符；在目标输出中作为每个被挖空片段的前缀引导符，并在末尾额外加一个哨兵 token 作为 EOS 结束符。这种设计使得模型能够按顺序、精确地生成多个被破坏的连续片段。
    • 训练细节：Pre-train 0.5M steps；Batch size = 128 sequences (sequence length=512，packing multiple seqs 65k tokens per batch)；Result in 34B trained tokens。
  • Supervised fine-tuning：
    • 语言理解/文本分类：GLUE / SuperGLUE
    • 摘要生成：CNN/Daily mail corpus
    • 问答：SQuAD
    • 机器翻译：WMT English to German, French, Romanian
  • Multitask SFT with Task Instruction：
    • 核心思想：Unified format to put task instructions as natural language in the input，enables transfer to new tasks。
    • 将所有下游任务转为“前缀 + 输入文本 → 输出文本”的统一格式，混合所有任务数据一起微调。损失函数与预训练相同（Decoder 端交叉熵），使用 teacher forcing。模型通过任务前缀区分不同任务，实现一个模型处理多种 NLP 任务。
    • 输入输出示例：
    • 后续发展：With more instruction tuning \(\rightarrow\) T0, Flan-T5。
      • T5 的“多任务 SFT”依赖固定任务前缀；指令微调改用大量自然语言指令 → 输出数据，显著提升零样本 / 新任务泛化能力。
      • T0 （arXiv 提交日期：15 Oct 2021，ICLR 2022）：基于 T5，用 P3（多任务、多提示模板）做指令微调；T0-11B 在多个零样本 NLP 任务上超过 GPT-3 175B，参数量约小 16 倍，展示了指令微调对零样本泛化的显著提升。
      • Flan-T5（arXiv 提交日期：20 Oct 2022，Journal of Machine Learning Research 2024）：基于 T5，用更大更多样的 Flan 2022 指令集合 + CoT 训练，性能全面超越 T0/T5，下游微调收敛更快、效果更好。

T5 训练&推理流程：

  • 训练：input 和 label 是分离的。Encoder 编码被破坏的输入，Decoder 用 teacher forcing 接收右移的 label（即：pad 起始 token + label[:-1] 序列除了最后一个 token 输入，预测完整的 label），通过 cross-attention 关注 Encoder 输出，对所有位置并行计算交叉熵 loss。
  • 推理：没有 label。Decoder 从起始 token 开始，自回归逐步生成，每步把已生成的 token 追加到输入中。使用 Beam Search（width=4, length penalty=0.6）保留最优候选，直到生成 EOS。
  • 核心区别：训练时所有位置并行计算 loss；推理时必须串行逐步生成。

指令微调补充：

  • 本质：用大量“自然语言指令 → 输出”数据训练，让模型学会遵循任意指令，提升零样本/新任务泛化。
  • 数据格式：通常含 instruction、input（选填）、output。常用 Alpaca 格式： 训练时填入固定模板：### Instruction: {instruction} ### Input: {input} ### Response: {output}，input 为空时省略 ### Input:。编码器输入为 instruction+input 拼接，解码器目标为 output。
  • 损失函数：掩码下一词交叉熵，只计算 output 部分；instruction 和 input 部分不参与 loss。
  • 训练：混合所有任务指令数据，按比例采样；T0 用 P3（多任务多模板），Flan-T5 用 Flan 2022 + CoT。
  • 推理：自回归生成，面对未见指令直接生成输出（零样本）；也可给少量示例（少样本）。
  • 与 T5 多任务微调区别：T5 用固定任务前缀，学执行特定任务；指令微调用自然语言指令，学遵循任意指令，泛化更强。
  • 注意：指令微调存在适应性与泛化权衡，效果依赖指令数据质量、多样性和模板一致性。

2.2 Architecture Improvements

2.2.1 SwiGLU

  • Swish 激活函数：
    • 公式：\(Swish(x) = x \sigma(\beta x)\)，其中 \(\sigma(x) = \frac{1}{1 + e^{-x}}\) 是 Sigmoid 函数。
    • 特点：平滑、非单调。在 PyTorch 中对应 F.silu（当 \(\beta=1\) 时）。
    • 函数图像：
  • FFN with ReLU（传统结构）：
    • 公式：\(FFN(x) = max(0, x \cdot W_1 + b_1) \cdot W_2 + b_2\)
    • 隐藏层维度：\(dim = 4d\)。
  • FFN with SwiGLU（LLaMA 结构）：
    • 公式：\(FFN_{SwiGLU}(x) = (Swish(x \cdot W_1 + b_1) \odot (x \cdot W_2 + b_2)) \cdot W_3 + b_2\)
    • 隐藏层维度：\(dim = \frac{2}{3} \cdot 4d\)。
    • 维度设计原因：SwiGLU 引入了额外的权重矩阵 \(W_2\)（门控分支），将隐藏层维度缩减为原来的 \(\frac{2}{3} \cdot 4d\)，以保持整体参数量与传统 ReLU FFN 大致相当。
  • 与 LLaMA 源码的对应：
    • LLaMA 源码中去掉了所有 bias 项（bias=False），公式变为 \(W_3(Swish(xW_1) \odot (xW_2))\)。
    • 源码对应关系：self.w1 对应 \(W_1\)（门控），self.w3 对应 \(W_2\)（值），self.w2 对应 \(W_3\)（输出投影）。
    • 前向实现：self.w2(F.silu(self.w1(x)) * self.w3(x))。其中 F.silu 即 Swish 激活函数。

2.2.2 Rotary Position Embedding（RoPE）

  • RoFormer: Enhanced Transformer with Rotary Position Embedding
  • arXiv 提交日期：20 Apr 2021
  • 作者苏剑林 Blog：Transformer升级之路：2、博采众长的旋转式位置编码
  • 作者：
动机与核心思想

传统的绝对位置编码（如 Sinusoidal、可学习位置编码）直接将位置信息加到 Embedding 上，而相对位置编码往往需要修改 Attention 矩阵的计算流程，难以保持形式上的统一。

RoPE 的核心思想是：“通过绝对位置编码的形式，实现相对位置编码的效果”。

  • 基本原则：让 Query 向量 \(\boldsymbol{q}_m\)（位置 \(m\)）与 Key 向量 \(\boldsymbol{k}_n\)（位置 \(n\)）的内积只依赖于两者的相对距离 \((m-n)\)，即：

\[\langle f(\boldsymbol{x}_m, m), f(\boldsymbol{x}_n, n) \rangle = g(\boldsymbol{x}_m, \boldsymbol{x}_n, m-n)\]

数学推导与原理

(1) 2D 基础情况

对于二维平面的特征向量 \((x_1, x_2)\)，RoPE 将位置 \(m\) 的注入表示为对向量进行角度为 \(m\theta\) 的旋转： \[f(\boldsymbol{x}_m, m) = \boldsymbol{R}_{\Theta, m}^{(2)} \boldsymbol{x}_m = \begin{pmatrix} \cos(m\theta) & -\sin(m\theta) \\ \sin(m\theta) & \cos(m\theta) \end{pmatrix} \begin{pmatrix} x_{m,1} \\ x_{m,2} \end{pmatrix}\]

  • 内积性质： 在计算位置 \(m\) 的 Query 与位置 \(n\) 的 Key 的 Attention 点积时： \[f(\boldsymbol{x}_m, m)^T f(\boldsymbol{x}_n, n) = \boldsymbol{x}_m^T \boldsymbol{R}_{\Theta, m}^{T} \boldsymbol{R}_{\Theta, n} \boldsymbol{x}_n = \boldsymbol{x}_m^T \boldsymbol{R}_{\Theta, n-m} \boldsymbol{x}_n\] 这里利用了旋转矩阵的性质 \(\boldsymbol{R}_m^T \boldsymbol{R}_n = \boldsymbol{R}_{n-m}\)。绝对位置 \(m\) 和 \(n\) 在相乘后转化为相对位置差 \(n-m\)。

  • 复数视角： 若将二维向量视作复数 \(\boldsymbol{x} = x_1 + \text{i}x_2\)，则旋转等价于乘以复指数 \(e^{\text{i}m\theta}\)：

\[\langle \boldsymbol{q}_m e^{\text{i}m\theta}, \boldsymbol{k}_n e^{\text{i}n\theta} \rangle = \text{Re} \left[ (\boldsymbol{q}_m e^{\text{i}m\theta}) (\boldsymbol{k}_n e^{\text{i}n\theta})^* \right] = \text{Re} \left[ \boldsymbol{q}_m \boldsymbol{k}_n^* e^{\text{i}(m-n)\theta} \right]\]

(2) 高维扩展

对于 \(d\) 维隐层向量（\(d\) 为偶数），RoPE 将 \(d\) 维空间切分为 \(d/2\) 个独立的二维子空间，每个子空间赋予不同的旋转频率 \(\theta_i\)：

\[\Theta = \{ \theta_i = 10000^{-2(i-1)/d}, \quad i \in [1, 2, \dots, d/2] \}\]

整体旋转矩阵为分块对角矩阵：

\[\boldsymbol{R}_{\Theta, m}^{(d)} = \begin{pmatrix} \cos(m\theta_1) & -\sin(m\theta_1) & 0 & 0 & \cdots & 0 & 0 \\ \sin(m\theta_1) & \cos(m\theta_1) & 0 & 0 & \cdots & 0 & 0 \\ 0 & 0 & \cos(m\theta_2) & -\sin(m\theta_2) & \cdots & 0 & 0 \\ 0 & 0 & \sin(m\theta_2) & \cos(m\theta_2) & \cdots & 0 & 0 \\ \vdots & \vdots & \vdots & \vdots & \ddots & \vdots & \vdots \\ 0 & 0 & 0 & 0 & \cdots & \cos(m\theta_{d/2}) & -\sin(m\theta_{d/2}) \\ 0 & 0 & 0 & 0 & \cdots & \sin(m\theta_{d/2}) & \cos(m\theta_{d/2}) \end{pmatrix}\]

3.1 Model Architecture & Model Size

Model Architecture

  • Decoder only

  • With modified initialization, pre-normalization, and reversible tokenization

    • reversible tokenization: 任何文本在经过 Tokenizer 编码（Encode）成 Token ID 序列后，再通过 Decode 还原回文本时，能够做到 100% 毫无损失、无歧义地精确复原原始文本。即：
    • \[\text{Decode}(\text{Encode}(\text{Text})) \equiv \text{Text}\]

  • Alternating dense and locally banded sparse attention patterns

  • Sparse Attention paper

    • Generating Long Sequences with Sparse Transformers
    • arXiv 提交日期：23 Apr 2019
    • 作者：Rewon Child; Scott Gray; Alec Radford; Ilya Sutskever
      • 全部来自 OpenAI
    • 官方 blog：sparse transformer
    • 主要贡献：
      • 引入注意力矩阵的稀疏分解，降低时间空间复杂度到 \(O(n\sqrt{n})\)
      • 引入注意力矩阵重计算（recomputation of attention matrices），节省显存
      • 引入更快的 attention kernel

Attention Score Matrix 与重计算存储占用分析：

Data type Stored Recomputed
1024 text tokens (several paragraphs) 1.0 GB 16 MB
32x32x3 pixels (CIFAR-10 image) 9.6 GB 151 MB
64x64x3 pixels (Imagenet 64 image) 154 GB 2.4 GB
24,000 samples (~2 seconds of 12 kHz audio) 590 GB 9.2GB
由于 Attention Score 是 \(n \times n\) 矩阵，导致存储占用随着序列长度 \(n\) 呈平方增长。

Sparse Attention Motivation

Even computing a single attention matrix, however, can become impractical for very large inputs. We instead use sparse attention patterns, where each output position only computes weightings from a subset of input positions. When the subset is small relative to the full set of inputs (say, \(\sqrt{N}\) elements instead of \(N\) elements), the resulting attention computation becomes tractable even for very long sequences, with an algorithmic complexity of \(O(N\sqrt{N})\) instead of \(O(N^2)\).


上图解释：

  • 上面一行，每两个小正方形，表示两个 Attention Head 分别可以看到一个 \(6 \times 6\) 的图片的哪些像素。
  • 下面一行，表示计算 Attention 时，某个输出位置可见的输入位置。
  • 按列看，三列分别表示：
    • 标准 Attention：两个 head 都可以看到所有前面位置。
    • strided：一个 head 只可以看前几个位置；一个 head 可以看前面 strided 跨步的位置。
    • fixed：一个 head 可以看 block 内的前几个位置；一个 head 只可以看固定的几个位置（图中表示 block 内最后一个位置）。

历史地位与演进：

  • GPT-3 论文中尝试了 Dense 与 Sparse Attention 层的交错堆叠。
  • FlashAttention 随着 FlashAttention 的出现，业内重新回归 Full Attention；
  • Modern Hybrid Model 目前一些模型为了应对超长上下文（如 1M+ Token）带来的 FLOPs/KV Cache容量等挑战，也采用了类似 GPT3 的 Hybrid Attention 机制：标准 Attention 与改进的 Attention 层（sliding window/linear/sparse 等各种 Attention 变体）交错。
